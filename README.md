# Almas Jewellers Showcase

Create a clean, modern and fully responsive jewellery store website for a fictional Pakistani brand named "Almas Jewellers".



This website is a portfolio project created by AK Web Design.



Important Design Instruction:



Do NOT reuse the layout, colors, sections or design of any previous fashion boutique or watch website.



Create a completely different website with a clean, modern and elegant jewellery store appearance.



Keep the homepage simple, professional and easy to browse.



Avoid unnecessary luxury effects and long pages.



Pages & Sections:



1. Home

- Hero Banner

- Heading: "Elegant Jewellery for Every Occasion"

- Short introduction

- Button: "Explore Collection"



2. Categories

- Rings

- Earrings

- Necklaces

- Bracelets

- Bangles

- Bridal Sets



3. Featured Collection

Display only 12 jewellery products with:

- High-quality images

- Product name

- Price



Price Rules:



- Rings: Rs. 10,000 – Rs. 15,000

- Earrings: Rs. 8,000 – Rs. 15,000

- Bracelets & Bangles: Rs. 12,000 – Rs. 25,000

- Necklaces: Rs. 25,000 – Rs. 40,000

- Bridal Sets: Rs. 35,000 – Rs. 50,000



Do NOT display unrealistic prices like Rs. 100,000, Rs. 500,000 or above.



4. About Us

Write a short introduction about Almas Jewellers as a Pakistani jewellery store offering elegant and affordable jewellery.



5. Contact

Include only:

- WhatsApp Button

- Instagram Icon

- Facebook Icon

- Contact Form



6. Footer

- Navigation Links

- Social Media Icons

- Copyright

- Website Designed & Developed by AK Web Design



Design Requirements:



- White background with Black and Gold accents.

- Modern typography.

- Clean UI.

- Elegant product cards.

- Soft hover animations.

- Fully responsive.

- Fast loading.



Important:



This is a fictional sample website created only for the portfolio of AK Web Design.



Display only jewellery.



Do NOT include clothing, handbags, shoes, watches or cosmetics.



Do NOT include shopping cart, wishlist, checkout or online payment.



Do NOT include Google Maps.



I will upload my own official logo.



Use my uploaded logo exactly as provided.



Do NOT redesign or modify my logo.



Use the logo in the Header, Footer and Browser Favicon.



I will also upload my own hero banner image.



Use my uploaded hero image as the homepage hero section.



Do NOT generate another hero image.



The final website should look like a clean and modern Pakistani jewellery store, completely different from the fashion boutique and watch store websites.
